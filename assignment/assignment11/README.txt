Assignment 11 - NumPy Basics

Run:
  python assignment/assignment11/assignment11_numpy.py

What it covers (school level):
1) Combine 1D and 2D arrays
2) Flatten 2D array into 1D
3) Reverse a numpy array
4) Max/Min, rows & cols, selection, sum using for loop, and elementwise add/sub/mul/div
5) Iterate 3D array using for loop and nditer
6) Mean, median, mode for two NumPy 2D arrays (mode returns all tied values)
