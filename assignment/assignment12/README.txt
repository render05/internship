Assignment 12 - NumPy

Run:
  python assignment/assignment12/assignment12_numpy.py

What this script does:
- 1D -> 2D reshape
- Print array attributes: shape, ndim, dtype, itemsize
- 3x3 array filled with 9
- 1D linspace between 25 and 125 (10 values)
- Convert list -> NumPy array
- Reverse 1D array
- 4x4x3 extraction and slicing
- Odd rows & even columns extraction
- Replace odd numbers with -1 using for-loops
- Indices of non-zero elements
- Element-wise add & multiply
- Dot product of two vectors
